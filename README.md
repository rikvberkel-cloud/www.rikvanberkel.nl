# rikvanberkel.nl

Publieke kopie van de website www.rikvanberkel.nl. Hier staan alleen de bestanden die online komen.

De bron, documentatie en werkafspraken staan in de privé repo `r010-as-a-service`. Pas de site daar aan en zet de sitebestanden daarna hierheen over. Zet hier nooit interne documenten, tarieven of adresgegevens neer.

Publiceren gaat via GitHub Actions bij elke push naar `main`.
